# 📞 CallCenter AI

AI-powered call center analysis system that automatically transcribes calls, identifies speakers, analyzes sentiment, and visualizes insights through a dashboard.

---

## 🚀 Features

- 🎙️ Speech-to-text transcription
- 👥 Speaker diarization (who spoke when)
- 😊 Sentiment analysis
- 📊 Dashboard visualization

---

## 🛠 Tech Stack

**Backend**
- Python
- FastAPI
- PyTorch
- Transformers

**Frontend**
- HTML
- CSS
- JavaScript

**AI / ML**
- Speech Recognition Model
- Speaker Diarization Model
- Sentiment Classification Model
