OMAZZ CALLING — Three.js UI integrated build

Run from this project folder:

Windows:
  python -m uvicorn backend.main:app --host 127.0.0.1 --port 9000 --reload

Then open:
  http://127.0.0.1:9000/

Important:
- Run the command from the project root so sqlite:///./callcenter.db resolves correctly.
- Three.js and Chart.js are currently loaded from CDN, so the browser needs internet access for the animated 3D background and charts.
- Existing backend/API/database logic is retained.
